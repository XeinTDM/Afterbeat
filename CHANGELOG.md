# Changelog

## 1.2.6

First GitHub release candidate for x64 Windows.

- Portable mouse clicking, keyboard input, and single-character Unicode text output.
- Fixed and variable pacing, counted and timed runs, hold activation, and an emergency stop shortcut.
- Fixed points, routes, dry runs, app filters, and stop zones.
- Local presets and settings recovery, keyboard navigation, and compact layouts.
- A Win32 delivery harness, benchmark methodology, and published trial data.
