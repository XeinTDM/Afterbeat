# Security policy

Security fixes target the latest published version of Afterbeat.

Report vulnerabilities privately through the repository's **Security → Report a vulnerability** form. Include the Afterbeat version, Windows version, reproduction steps, and the impact you observed. If the form is unavailable, open an issue asking for a private contact and omit the vulnerability details. [Private vulnerability report](https://github.com/XeinTDM/Afterbeat/security/advisories/new)

For ordinary bugs, use [GitHub Issues](https://github.com/XeinTDM/Afterbeat/issues). Before sharing diagnostics, remove private paths, app names, and other personal data.
